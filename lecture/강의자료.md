```hcl
terraform {
  required_version = ">= 1.9"
```

### [함정] generate-config 주의
- 생성된 `generated.tf`는 **초안**. 리뷰 후 `import` 블록은 apply 뒤 지워도 됨(1회성).
- data source나 이미 관리 중인 리소스가 있으면 생성 안 됨.

### [개념] ⭐ 왜 OIDC인가 (장기 키 vs 임시 자격)
CI(GitHub Actions)에서 AWS를 쓰려면 자격증명이 필요하다.
- **장기 AccessKey를 Secret에 저장** = 유출되면 무기한 악용, 순환(rotation) 관리 부담, "누가 썼는지" 추적 어려움.
- **OIDC**: GitHub이 워크플로 실행마다 서명된 **단기 토큰**을 발급 → AWS가 이를 신뢰해 **몇 분짜리 임시 크레덴셜** 부여. 저장할 비밀키가 **아예 없음**.
```
 [GitHub Actions] --OIDC 토큰--> [AWS IAM OIDC Provider]
                                        │ AssumeRoleWithWebIdentity
                                        ▼
                                 임시 자격(15분~1시간)
```

### [실습] 5. AWS 측 — OIDC provider + Role (콘솔/CLI 택1, 개념 확인용)
IAM → Identity providers → Add provider → **OpenID Connect**
- Provider URL: `https://token.actions.githubusercontent.com`
- Audience: `sts.amazonaws.com`

그 다음 Role 생성 — 신뢰 정책(trust policy):
```json
{
  "Version": "2012-10-17",
  "Statement": [{
    "Effect": "Allow",
    "Principal": { "Federated": "arn:aws:iam::<ACCOUNT_ID>:oidc-provider/token.actions.githubusercontent.com" },
    "Action": "sts:AssumeRoleWithWebIdentity",
    "Condition": {
      "StringEquals": { "token.actions.githubusercontent.com:aud": "sts.amazonaws.com" },
      "StringLike": { "token.actions.githubusercontent.com:sub": "repo:<ORG>/<REPO>:ref:refs/heads/main" }
    }
  }]
}
```

### [실습] 6. GitHub Actions 워크플로 (키 없음)
`.github/workflows/terraform.yml`:
```yaml
name: terraform-plan
on: [push]
permissions:
  id-token: write      # OIDC 토큰 발급에 필수 ⭐
  contents: read
jobs:
  plan:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - uses: aws-actions/configure-aws-credentials@v4
        with:
          role-to-assume: arn:aws:iam::<ACCOUNT_ID>:role/boaz-gha-oidc
          aws-region: ap-northeast-2
      - uses: hashicorp/setup-terraform@v3
      - run: terraform init
      - run: terraform plan
```

### [확인] OIDC 동작
Actions 로그에서 `configure-aws-credentials`가 `AssumeRoleWithWebIdentity`로 임시 크레덴셜을 획득 → `terraform plan` 성공. **어디에도 AccessKey를 저장하지 않았다.**
